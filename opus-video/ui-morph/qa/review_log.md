# 验收记录

## 第 1 轮（小样，30fps 无运动模糊）
问题：
1. 全片：显隐函数把 `display:flex` 覆盖成 `block`，按钮文字没居中，灵动岛、提示条排版散了（「Chart exportedUndo」）。→ 改为恢复 CSS 默认 display。
2. 全片：每个状态在画面里偏小（取景系数 0.4/0.42，上限 3.0）。→ 改为 0.5/0.5，上限 3.4。
3. 8.0s：开关关闭态的灰底带出了白底面板的投影。→ 投影只在接近纯白时出现。
另：音量条拉满时读不出是滑块 → 加了深色圆钮。
