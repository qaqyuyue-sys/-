# brief：常青文创设计 · 一个形状的 12 种界面（品牌版）

基于 `opus-video/ui-morph`（方案 A）换成用户品牌。品牌素材：`brand/logo-source.png`（用户提供），已矢量化为 `brand/emblem.svg` / `wordmark.svg` / `subline.svg`（`brand/trace_logo.py`）。

```text
<role>
你是一位动态设计师，也是一位创意程序员，擅长用代码做出有设计感的视频。
</role>

<inputs>
主题：常青文创设计的品牌动效短片。一个形状不切镜头，连续变形成 11 种界面组件，最后变成品牌徽标并展开完整标志。
想让观众记住的一句话：常青文创设计，毕业季文创一站搞定。
原材料：用户提供的 logo（徽标 + 主字标「常青文创设计」+ 副标）；界面文案为示意，需用户核对。
规格：16 秒（8 小节），1920×1080（16:9），60fps，4 子帧运动模糊；不循环，结尾停在标志上。
品牌：主色海军蓝 #09164A（从 logo 取色），冷白画布 #F3F4F8，白 #FFFFFF，关闭态灰 #C5C9D6，次要文字 #8E96B8；中文 Noto Sans SC（只带用到的字形分包），西文数字 Geist；标志一律用矢量化原图，不重新排字。
声音：代码合成配乐 120 BPM（Am–F–C–G–Am–F–G，第 8 小节回到 Am 收尾），界面音效落在动作帧，标志出现时一记低频重音 + 提示音；不配音。
</inputs>

<direction>
风格：Dribbble 级界面动效。全片只有一个形状，从不切镜头：每个状态都是同一个元素改变宽、高、圆角和颜色，内容用短暂的模糊切换。光标驱动每一次变化，真实的点击和拖拽。
整片只用海军蓝 / 白两色（与 logo 一致），同一个元素在每个镜头里的样子都一致。
画面上的字少而大；动画全部用闭式弹簧，最多一点点回弹。
镜头：随状态推拉，让每个状态占满画面（宽约 50%，高约 45%）；镜头用沉稳的弹簧（w 9，ζ 0.95）。
结尾：形状变成圆形徽标（白底海军蓝），向左让位，主字标从左往右擦出，副标从中间向两边展开，完整标志居中停留 2 秒。
禁止：弹跳缓动、粒子爆炸、发光、界面上的渐变、图标描边粗细不一、空拍、模板感、深色背景居中大字、所有元素同时淡入、重新排版或改动 logo 字形。
</direction>

<structure>
节拍网格：120 BPM，每拍 0.5s，8 小节 = 32 拍；重拍（0/2/4/…/14s）放最大的变化。
小节 1｜0.0–2.0s　光标停在「预约设计」按钮上 → 0.5s 点击 → 1.0s 收成加载圈。
小节 2｜2.0–4.0s　2.0s 对勾 → 3.0s 灵动岛「新订单 · 毕业纪念册」（左侧小徽标，右侧跳动的声波条）。
小节 3｜4.0–6.0s　4.0s 展开成作品集播放器（封面为徽标，「2026 毕业季作品集 / 常青文创设计」）→ 4.5s 播放变暂停 → 5.0–5.9s 拖动进度条。
小节 4｜6.0–8.0s　音量条，拖过头被拉长，7.45s 松手弹回。
小节 5｜8.0–10.0s　开关翻转 → 圆钮流动成标签「文创 / 礼品 / 画册」→ 9.5s 点「礼品」。
小节 6｜10.0–12.0s　折线图「全年排期 · 毕业季」，悬停 6 月高峰 → ⌘K 输入「毕业季」→ 筛出「毕业季文创方案」。
小节 7｜12.0–14.0s　12.0s 回车 → 提示「方案已发送」→ 13.0s 变成圆形徽标 → 13.5s 主字标擦出，13.9s 副标展开。
小节 8｜14.0–16.0s　完整标志停留，配乐回到 Am 一记收尾。
</structure>

<build>
1. 画面：单个 HTML 文件（index.html），HTML/CSS/SVG，Geist 本地字体，不用外部图片和素材。
2. 页面暴露 window.render(t)，画出第 t 秒；所有样式在 render(t) 里由 t 算出来：不用 CSS transition、计时器，帧和帧之间不保存状态。
3. 弹簧是闭式阶跃响应；一个值多次改变目标时，是每次改变各自一个弹簧的叠加，仍是 t 的纯函数（lib.js 的 track）。
4. 指示条和开关圆钮的两条边各走不同弹簧，前沿拉伸领先后沿。
5. 拖拽是直接操控：按住时数值由光标位置算出；松手后从当时的位置弹回。
6. 音效时间表从 index.html 的同一份事件表导出（window.EVENTS），配乐按同一节拍网格合成；混音后 -14 LUFS，峰值低于 -1 dBTP。
7. 渲染：Playwright 逐帧调用 render(t) 截图，每帧 4 子帧，ffmpeg tmix 混合成 60fps 运动模糊。
8. 正式渲染前，每拍渲一帧静帧检查：是否在网格上、是否拥挤、是否易读。
</build>

<gotchas>
被镜头缩放的元素、带文字的元素不要加 will-change，否则文字会糊。
在变形容器里切换的文字要有自己的进场和出场时间，否则新旧文字会叠在一起。
标志段的所有弹簧在 14.5s 前静止，最后 1.5 秒画面完全不动。
本地 file:// 页面不能用外部 SVG 做遮罩：logo 路径由 brand/logo.js 内联。
字体加载完（document.fonts.ready）再置 window.ready = true。
</gotchas>

<start>
按小节顺序制作，每个小节完成后渲静帧检查；全部完成后渲 30fps 无模糊小样核对节奏，再出正式版和抽帧图验收，然后交付。
</start>
```
